Shoot byes?
With an odd number of archers, one archer has no opponent each pass. Yes: they still shoot, on their own, so every archer shoots every pass. No: they sit that pass out, which adds passes to the event so that everyone still shoots all of their arrows.

Setup mode:

Simple setup: every archer shoots the same distance at the same target face size (the standard single-face target, not 3-spot). Distances up to 25 m / 25 yd count as indoor (indoor arrow size, and Compound archers score only the inner ring as 10); longer distances count as outdoor.
